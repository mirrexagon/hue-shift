# Hue Shift
## Ideas
Raindrops theme: a soft raindrop/water ripple in a random location on the screen each beat.

Play with expectations: eg. a beat where obstacles move and you don't?

If using staged introduction of player blocks, in four beats, flash half-transparent and ethereal.


## Menu items

At least to start with:

1. Logo
2. Music
3. Number of player blocks
4. Grid size setup
5. Start

---

Eventually:

1. Logo
2. Theme
3. Music
4. Number of player blocks
5. Grid/obstacle layout
6. Start

---

Make start block breathe or something to show interactivity.


## Modifiers
- Wrong goal block is obstacle
- Other player block is obstacle
- Time limit, step limit, etc.
- Game speed: faster, slower, changes every few beats
